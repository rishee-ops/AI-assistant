# Edit Style & Preferences

Claude reads this file before proposing any edit plan. Change the values here
to change how videos get edited by default. Delete the `TODO` notes as you
lock choices in.

## Defaults

- **Aggressiveness:** `Medium tighten` — remove filler words, false starts,
  dead air, and trim rambling tangents; preserve the message and length where
  it matters. _(Options: Light polish | Medium tighten | Aggressive cut.)_
- **Approval before destructive cuts:** `Yes` — show the plan and wait.
  _(Set to `No` to let Claude cut automatically per these rules.)_
- **Filler words to remove:** um, uh, er, like (when a crutch), you know, so
  (sentence-start), basically, actually (when filler).
- **Max pause to keep:** 1.5 seconds — tighten anything longer.
